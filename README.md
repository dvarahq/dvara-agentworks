# DVARA AgentOS OSS

This repository is the production-capable open-source core of DvaraOS. The intended license is Apache-2.0, subject to the project's final licensing publication.

Detailed DvaraOS architecture, ADRs, design records, audits, and implementation specifications are maintained in the private `dvarahq/dvara-agent-os-enterprise` repository. This public repository is not an architecture source of truth; moving the documentation does not change which DvaraOS capabilities are OSS.
